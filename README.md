# CoMind 桌面版

**CoMind** 是基于 **Open Interview Assistant** 扩展的智能办公助手。提供侧栏导航、资料库、回答区和复盘界面，接入真实模型、Chrome 网页采集与 Electron 原生悬浮窗。

快速了解项目：[项目简介](INTRODUCTION.md)。源码仓库：[azhsmesos/CoMind](https://github.com/azhsmesos/CoMind)。

## 安装与首次使用

重新构建后，在 `release/` 中选择对应的 CoMind 安装包（旧版本安装包不会随源码改名）：

- Mac Apple Silicon（M 系列）：`CoMind-1.0.0-mac-arm64.dmg`
- Mac Intel：`CoMind-1.0.0-mac-x64.dmg`
- Windows x64：`CoMind-1.0.0-win-x64.exe`

Mac 打开 DMG 后，将“CoMind”拖入 Applications；Windows 运行安装程序。无需安装 Node.js，不需要 `.env`。这些包供个人或小范围使用，未进行开发者证书签名、公证，系统可能要求手动确认打开。不要把一个平台的包用于另一个平台。

1. 打开应用，进入 **应用设置 → AI 模型连接**。
2. 默认已选 DeepSeek 并预填模型和接口地址，只需填写 API Key；也可选择豆包、GLM 或自定义服务并填写账户可用的模型 ID。
3. 保存连接，点击 **测试**。多份配置可通过 **启用** 切换。
4. 在工作台输入题目，点击 **添加题目并生成**。没有会话时会自动创建。
5. 点击 **打开悬浮窗**，将回答或已保存的提词稿放到独立置顶窗口。
6. 可以记录自己的实际作答，结束会话后在 **历史与复盘** 生成真实分析或导出 Markdown。

第一次使用资料库时内容为空。简历、JD、固定问答在保存后用于回答生成；AI 整理结果可先修改再保存。没有记录实际作答的会话只做参考答案分析，不生成个人表现评分。

**简历上传**：在「我的资料库 → 简历与岗位 → 个人简历」点击「上传并解析」，支持 PDF（包括扫描版）、Word（`.doc` / `.docx`）和 PNG / JPEG / WebP / GIF 图片。单文件最大 20 MB，PDF 最多 10 页。PDF 在本地逐页转成图片，Word 在本地提取正文、表格和文本框，再发送给当前模型解析；PDF 和图片需要支持视觉的模型，例如 `deepseek-flash`。无需安装 Office。解析结果填入可编辑草稿，检查后点击「保存资料」才用于后续回答；解析失败保留原草稿。加密文件请先解除密码，图片形式的 Word 请另存为 PDF 上传。

**悬浮窗回答**：普通问题直接展示具体答案；算法或编程实现题只展示 2～3 句话的思路和完整 Java 代码。新回答的提示词要求 Java 8+、必要的类和方法及边界处理，不再展开冗长的澄清、复述和推演。已保存的旧回答保留，点击「重新生成」可应用新的回答方式。

## 模型配置

| 服务 | 默认 API Base URL | 模型字段 |
|---|---|---|
| 豆包 / 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` | 已开通的模型 ID 或 `ep-…` 推理接入点 |
| DeepSeek | `https://api.deepseek.com` | 默认 `deepseek-flash`，支持文本与图片理解 |
| GLM / 智谱 | `https://open.bigmodel.cn/api/paas/v4` | 账户可用的模型 ID |
| 自定义 | 用户填写 | 用户填写 |

支持 **OpenAI Chat Completions** 与 **Anthropic Messages**，因此可以继续使用 Claude。Anthropic 的官方 Base URL 可填写 `https://api.anthropic.com`。Base URL 不包含 `/chat/completions` 或 `/messages`；应用自动拼接协议端点。不同套餐（例如 Coding Plan）可能需要不同地址，请填写对应服务商给出的接口根地址。

模型 ID 不强制绑定某一代模型，也不自动切换服务商。回答生成、资料优化、复盘均使用当前启用的配置。服务需要能够返回正文文本和 JSON；应用不会将 `reasoning_content` 作为答案。模型网络错误、鉴权失败、额度限制、超时和格式错误都会显示，**不会返回虚构的兜底答案**。

DeepSeek 使用 **OpenAI Chat Completions** 协议，按[官方图像理解文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)向 `/chat/completions` 发送请求：普通问题发送文本，整屏截图以 `image_url` 内容块携带 Base64 图片，与问题一起交给 `deepseek-flash`。保存后，第一份配置自动启用；已有其他配置时点击 DeepSeek 卡片的 **启用**。已有 DeepSeek 配置可编辑模型 ID 为 `deepseek-flash`，API Key 留空会保留原密钥。**测试**按钮检查文本连接，图片理解可通过工作台的整屏截图验证。

## Chrome 网页采集

1. 在应用设置中点击 **打开扩展目录**。
2. Chrome 地址栏输入 `chrome://extensions`，开启开发者模式。
3. 选择 **加载已解压的扩展程序**，选择刚打开的 `browser-extension` 文件夹。
4. 打开普通题目网页，等待题目加载，按 Mac `⌘ Shift U` / Windows `Ctrl Shift U`，或点击扩展弹窗的 **发送当前页面**。

扩展名为“CoMind 网页助手”。首次自动配对；恢复配对时先在应用设置中点击 **重新配对**，再在扩展中配对，窗口有效期为 60 秒。扩展目录固定在用户数据目录，升级应用不需要重新选择路径。

如果快捷键没有反应，检查 `chrome://extensions/shortcuts` 是否绑定成功。扩展弹窗会显示具体错误。浏览器内部页面、纯图片题目及无法读取的跨域 iframe 内容可使用整屏截图识题。

暂停会话时，网页采集暂存（最多 20 道），继续后依次生成。结束暂停会话会将待处理题目保存为未生成的回合。

## 桌面行为

### 手机局域网查看

1. 在电脑工作台点击 **手机查看 → 开启共享**，有多个网卡时先选择手机所在网络的地址。
2. 手机与电脑连接同一可互访的 Wi-Fi / 局域网，扫描二维码，或复制完整网址到手机的 Safari / Chrome。
3. 手机实时查看当前会话问答；生成期间保留前面的答案，完成后立即更新。支持较早问答分页、代码横向滚动和复制。手机无需安装 App 或填写 API Key。

手机端只读，不提供截图、提问或修改配置。只传输当前会话的问题和答案，不传输截图原图、会议全文、资料库或密钥。暂停和结束会话后保留已收到问答；删除或切换会话时同步清除或替换列表。

- 仅在可信局域网使用：HTTP / WebSocket 传输未加密，持有完整链接的人可阅读当前会话。开启共享时会生成随机访问令牌；**重置访问链接**会立即断开旧连接并使旧链接失效，最多连接 5 个页面。
- 手机页面从网址移除令牌，仅在当前标签页的 sessionStorage 中保存，以支持刷新；不会持久保存问答或写入电脑日志。答案或代码引用的个人经历属于回答内容，也会随答案同步。
- 电脑进入托盘后共享继续；退出应用即关闭，重启后须手动开启。手机断线后自动重连，锁屏或后台期间不保证持续接收，回到前台会重新同步最近 50 条，可继续加载更早记录。
- 网络地址变化后须重新开启并扫码；无法连接时检查电脑防火墙、访客 Wi-Fi 的设备隔离和 VPN。可先关闭共享再选择其他局域网地址。链接仅适用于当前网络，不支持公网远程访问。
- 普通 HTTP 页面可能不能直接写入系统剪贴板，此时会选中内容，长按选择“复制”即可。

### 会议语音识别（Mac）

在 **应用设置 → 会议语音识别** 选择语音识别模型，填写阿里云百炼北京地域的 **Workspace ID** 和独立的 **语音 API Key**，保存后测试连接。支持 `qwen3-asr-flash-realtime`（默认）、`fun-asr-realtime`、`paraformer-realtime-v2`。旧配置继续使用千问；切换时 API Key 留空可保留已有密钥，需确保账号已开通所选模型。DeepSeek 的 Key 不能代替百炼 Key。官方参考：[百炼实时语音识别](https://help.aliyun.com/en/model-studio/real-time-speech-recognition-user-guide)。

会议系统声音转写与模拟面试麦克风共用所选模型。保存语音配置会停止当前识别和未完成的语音自动任务，再次开始后使用新模型；选择会在重启后保留。千问使用 Realtime 协议，Fun-ASR 与 Paraformer 使用 Inference 协议，应用自动适配连接地址、音频发送和转写结果。豆包及本地 Whisper 暂未接入此选择列表。

在工作台点击 **开始会议识别**，即可实时转写电脑播放的系统声音，适合戴耳机开会。只采集系统声音，不启用麦克风，也不区分会议软件或远端说话人；其他应用播放的语音同样会被识别。系统音频上传百炼，转写文字由当前启用的回答模型判断问题，两个服务分别计费。原始音频只在内存中处理，不写入文件。

开启 **自动回答完整问题** 时，服务端静音断句 800 毫秒，再等待 800 毫秒合并补充，结合最近两分钟上下文判断完整提问。普通发言只记录，“介绍一下”“解释一下”等请求也可触发回答。问题串行处理，60 秒内重复问题去重；手动输入、截图和网页采集优先。队列满 10 条时暂停自动答题，转写继续，重新开启可继续处理队列。模型判断可能漏判，可点击每条文字旁的 **作为问题回答**。

主窗口进入托盘后继续转写；悬浮窗保留位置、穿透状态和上一条完整答案，后台回答完成后更新，不重新激活已显示的窗口。点击 **停止会议识别**，或暂停、结束、删除会话、切换模型、退出应用时立即停止采集和未完成的自动任务；恢复会话或重启应用不会自动开始录音。

最终文字和问题关联以追加记录保存在本机，按每页 50 条读取，可在历史中回看并随会话导出。识别中间文本只在内存显示，时间为本机收到转写的时间。断线按 1、2、4 秒最多重试三次，期间的语音不补传，记录中标注转写缺口；鉴权、配额错误直接停止。

macOS 需要 **录屏与系统录音** 权限。应用使用 Electron ScreenCaptureKit 音频路径；开发启动时需为实际终端（例如 iTerm2）授权并完全重启。系统权限拒绝、音轨结束或音频处理长时间没有数据时会停止并提示。仅当前 Mac 为首版验收平台，Windows 不提供开始入口。真实云端转写效果和时延需使用有效百炼凭证实机验证。

### 快捷键与整屏截图

侧边栏 **快捷键** 可设置全局快捷键，也可点击“截图并自动解答”。默认截图快捷键为 **Mac ⌘+Shift+S / Windows Ctrl+Shift+S**。页面显示实际注册状态和最近触发时间；注册失败不会显示保存成功，解除占用后再次保存同一快捷键会重试。已有自定义快捷键会保留。

也可设置 `F1`；Mac 部分键盘需要按 **Fn+F1**。输入 `Fn+F1` 时应用保存为 `F1`，是否需要 Fn 由系统键盘设置决定。若它打开了其他工具的截图界面，请更换组合键，或先解除其他工具的占用。CoMind 直接截取整屏并自动提交，不打开圈选界面；其他工具产生的截图不会自动上传到本应用。

截图快捷键支持按键录入：点击输入框，直接按组合键或功能键，自动识别后点击“保存快捷键”。Esc 取消本次录入，Backspace / Delete 清空后保存可停用。录入期间暂停本应用全局快捷键，离开输入框后恢复；系统或其他应用独占的按键仍可能无法录入。

触发后直接截取鼠标所在的整个屏幕，自动发送给当前启用的模型识别和生成回答，无需圈选或确认。保持主窗口和悬浮窗的位置、显示与穿透状态，不弹出截图窗口。建议先打开题目页面，再使用快捷键；多屏使用时先将鼠标移到目标屏幕。整屏可见内容都会提交给模型，悬浮窗若遮住题目，请先移开。

未配置模型时图片保存在会话中，配置支持图片输入的模型后可重试；支持 OpenAI 兼容及 Anthropic 图片消息。上传失败会显示错误，会话暂停时需先继续会话。

快捷键页面的“截图日志”默认折叠，终端和页面仅显示开始、上传、完成或错误等主要状态。权限、屏幕读取、图片尺寸等详细诊断保存在页面所示的本地 `screenshot.log`，超过约 1 MB 时轮换，保留一份旧日志；不记录截图内容或模型密钥。“最近收到截图快捷键”仅表示按键已触发，不代表截图或识别已完成。

macOS 首次使用需授予屏幕录制权限；开发模式可能需要允许 Electron 或启动它的终端，授权后重启应用。截图压缩为 JPEG，长边最大 2560 像素。

关闭主窗口后进入托盘；通过托盘打开工作台或退出。悬浮窗默认可鼠标操作，可拖动标题栏、调整窗口尺寸。开启穿透后，通过快捷键、托盘或主窗口恢复。

| 功能 | 默认快捷键 |
|---|---|
| 整屏截图并自动解答 | `Cmd/Ctrl Shift S` |
| 生成最新题目 | `Cmd/Ctrl Shift Enter` |
| 显示或隐藏悬浮窗 | `Cmd/Ctrl Shift B` |
| 切换鼠标穿透 | `Cmd/Ctrl Shift M` |
| 悬浮窗向上 / 向下翻页 | `Cmd/Ctrl Alt ↑` / `Cmd/Ctrl Alt ↓` |
| 悬浮窗代码向左 / 向右滚动 | `Cmd/Ctrl Alt ←` / `Cmd/Ctrl Alt →` |
| 开放重新配对窗口 | `Cmd/Ctrl Shift P` |

侧边栏“快捷键”支持修改这些快捷键，并显示占用或格式冲突；浏览器快捷键在 Chrome 中设置。留空可停用应用快捷键。

穿透模式下，鼠标滚轮会交给下方窗口。使用上面的翻页快捷键即可滚动悬浮窗答案，长代码可左右滚动，不需要关闭穿透或切换焦点。Mac 的 Alt 对应 Option（⌥）。悬浮窗会显示实际已注册的按键；未启用或被占用时请在“快捷键”中重新设置。也可按 `Cmd/Ctrl Shift M` 暂时关闭穿透，直接使用滚轮。

内容保护仅用于悬浮窗，并不能保证所有录屏/共享方式都不可见。部分 macOS ScreenCaptureKit 捕获不受保护。首版不包含录音、语音转写、手机同步。

## 数据与隐私

品牌升级后会继续使用已存在的旧版桌面数据目录，保留资料、会话和浏览器扩展路径；应用标识保持稳定。

- 使用 Electron 用户数据目录下的 `desktop-state.json` 持久化资料、会话、模型配置和扩展 Token，采用版本号与原子替换写入。
- API Key 由 `safeStorage` 使用系统加密能力加密；不回传界面、不存入 localStorage、不打进安装包。系统加密不可用时只在本次运行的内存中保留。
- 题目和资料在生成时发送给你配置的模型服务，未使用额外的中转服务。
- 会话和资料本身未加密，依赖本机账户和磁盘保护；删除会话会从应用持久化状态移除。
- 不自动导入旧网页 localStorage 中的示例、历史或密钥。
- 不自动上传日志、遥测或更新。

## 本地开发

建议 Node.js 22 或更高版本：

```bash
npm ci
npm run dev
```

`npm run dev` 先构建独立手机页面，再同时启动 Vite 与 Electron，前端端口为 5180。首次运行可能下载 Electron 二进制，下载完成后才会出现桌面窗口。桌面主进程或手机页面修改后需重新启动开发命令。

```bash
npm run typecheck
npm test
npm run test:e2e
npm run test:screenshot
npm run test:voice
npm run test:mobile
npm run dist:mac
npm run dist:win
npm run test:packaged
```

- 单元/协议测试使用本机 HTTP 测试服务器与合成凭据，不使用个人 API Key。
- 端到端测试使用真实 Electron 窗口及隔离的临时数据目录；截图输出到 `test-results/`。
- 截图专项测试使用合成屏幕图片和本机模拟模型，验证按钮和快捷键自动提交整屏、窗口状态不变、错误提示和重启保存；不读取真实屏幕或调用付费模型。真实屏幕权限和具体视觉模型仍需实机验证。
- 语音专项测试使用真实隐藏 Electron 渲染器、AudioWorklet、合成音轨、本机 WebSocket/模型接口，验证自动答题、停止、权限隔离、窗口状态和记录保存；不会录制真实会议或调用付费接口。
- 手机专项测试使用回环地址、隔离的 Electron 和 390px 宽的普通网页，验证鉴权、二维码入口、实时答案、分页、复制降级、断线恢复及悬浮窗状态；真实手机扫码、实际局域网防火墙和 Safari 行为仍需实机验收。
- 打包到 `release/`，包含运行时，无需开发服务器。
- `test:packaged` 直接启动当前架构的打包应用；可用 `COMIND_EXECUTABLE` 指定可执行文件、`SMOKE_ARCH` 指定 Mac 架构。
- `.github/workflows/desktop.yml` 在 macOS ARM、macOS Intel 和 Windows x64 原生 runner 上构建并运行测试，只上传构建产物，不自动公开发布。
- Windows 包可以在 Mac 上交叉构建，但 **Windows 运行通过必须以 Windows runner 或实机结果为准**。

`src/` 为主界面及悬浮窗，`shared/` 定义 IPC 类型，`electron/` 为主进程、模型适配、会话与存储，`extension/` 为 Chrome 扩展。原始 UI 参考目录已移除，开发和构建统一从项目根目录执行。

退出快捷键默认是 **Control+C**（Mac 使用 Control，不是 Command）。在「快捷键 → 退出整个应用」点击输入框后按组合键，点击「保存快捷键」生效；Backspace / Delete 清空后保存可停用。触发后完整退出主窗口、悬浮窗和托盘，并停止会议识别及手机共享。
